Glifos 8×8 usados como máscara CSS (`.pi .pi-cursor`, `.pi-down`, `.pi-check`, `.pi-cross`) para herdar `currentColor`; os arquivos aqui estão pintados em `ink` só para visualização. Sempre `aria-hidden`.

- `cursor` ▶: item ativo, em foco ou em hover de menus e abas (pisca em 2 quadros).
- `down` ▼: continuação na caixa de diálogo e seta do select.
- `check` ✓ / `cross` ✗: palavra-chave encontrada / faltando, sempre junto da cor.
