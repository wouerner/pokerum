# EngineBadge

Selo do algoritmo de avaliação: nome, tipo e marca de padrão.

## O que você fornece
`name`, `kind` (`heuristic` → Heurístico, `llm` → LLM, `external_api` → API externa, `database` → Banco de dados) e `isDefault`.

## Regras
Nome em `tag-px` (Silkscreen 16px); tipo em chip `label` (Nunito 800 14px) com glifo de texto (ƒ, ✦, ⇄, ▤) e matiz próprio; "padrão" em contorno tracejado `ink-3`. Use em abas de ranking, cards de avaliação e no formulário de vaga.
